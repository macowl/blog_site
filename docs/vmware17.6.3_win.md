## 一、前置准备

### 1. 硬件与 BIOS 虚拟化开关

- CPU 必须开启虚拟化：`Intel VT-x` / `AMD-V`，在主板 BIOS/UEFI 打开
- Windows 宿主：关闭`Hyper-V`（如果开启会导致 VMware 无法启动）

```
# 管理员CMD，关闭Hyper-V，重启生效
bcdedit /set hypervisorlaunchtype off
```

- 内存建议：宿主至少 16G，分配给虚拟机不要超过物理内存一半

### 2. 软件下载

博通官网下载 VMware Workstation Pro，**现已免费商用 / 个人使用，无需密钥**。
准备好操作系统 ISO 镜像（Windows / Linux）。

## 二、安装 VMware Workstation

1. 运行安装包，接受许可协议
2. 选择安装路径，建议不要放 C 盘
3. 可选：勾选增强型键盘驱动（虚拟机捕获键盘）
4. 下一步完成安装，重启电脑。

## 三、新建虚拟机（标准向导）

1. 首页点击 **创建新的虚拟机**
2. 选择「典型 (推荐)」→ 下一步
3. 安装来源：**安装程序光盘映像文件 (iso)**，选中你的系统 ISO

> 
> 也可以选择「稍后安装操作系统」，手动配置硬件（推荐进阶用户）

4. 选择客户机操作系统：Windows / Linux，选择对应版本
5. 设置虚拟机名称，选择虚拟机文件存放目录（剩余空间充足的盘）
6. 指定磁盘容量：
   - 最大磁盘大小：Win10 建议≥60G，Ubuntu≥30G
   - 推荐：**将虚拟磁盘存储为单个文件**，性能更好
7. 点击「自定义硬件」，修改资源：
   - 内存：Win10 推荐 4G，Linux 最小 2G
   - 处理器：核心数，不超过宿主物理核心总数
   - CD/DVD：确认绑定 ISO 镜像
   - 网络适配器：默认 NAT
8. 关闭硬件窗口 → 完成。

## 四、虚拟机硬件网络模式说明

表格

| 模式 | 作用 | 适用场景 |
| --- | --- | --- |
| NAT（默认） | 虚拟机共享主机 IP，可上网，外部无法主动访问虚拟机 | 日常上网、开发，推荐新手 |
| 桥接模式 | 虚拟机和宿主机在同一局域网，独立 IP，局域网设备可访问 | 局域网测试、服务器调试 |
| 仅主机 (Host-only) | 虚拟机和宿主机私有网络，**不能访问外网** | 隔离测试、内网实验 |

## 五、开机安装系统 + 安装 VMware Tools

> 
> VMware Tools 是虚拟机驱动包，**必须安装**，实现：复制粘贴、文件拖拽、自动适配分辨率、鼠标自由进出虚拟机。

1. 点击「开启此虚拟机」，点击窗口捕获鼠标（`Ctrl+Alt`释放鼠标）
2. 按照 ISO 引导，安装客户机操作系统
3. 系统安装完成后，在 VM 顶部菜单：`虚拟机 → 安装VMware Tools`
4. 虚拟机内会挂载 Tools 光盘，运行安装程序，一路下一步，重启虚拟机。

> 
> Linux（Ubuntu/Debian）可命令行安装：

```
sudo apt update
sudo apt install open-vm-tools open-vm-tools-desktop -y
```

## 六、核心常用功能

### 1. 快照（Snapshot）⭐非常重要

> 
> 快照：保存虚拟机当前完整状态，随时回滚，测试、调试必备。
> ⚠️ 快照不是备份！大量快照会占用巨大磁盘空间，长期环境不要依赖快照。

操作：

1. 虚拟机**关机 / 开机状态都可以**（关机快照更稳定）
2. 顶部菜单 `虚拟机 → 快照 → 拍摄快照`
3. 填写名称 + 备注（例如：纯净系统，未装软件）
4. 需要恢复：`快照管理器`，选中快照，点击「转到快照」，虚拟机直接恢复到当时状态。

### 2. 共享文件夹（宿主机 ↔ 虚拟机互传文件）

1. 虚拟机**必须关机**，不能开机修改
2. `虚拟机 → 设置 → 选项 → 共享文件夹`
3. 选择「总是启用」，点击「添加」，选择宿主机本地文件夹
4. 设置权限：只读 / 可读写
5. Windows 虚拟机：共享目录在 `网络位置 → VMware Shared Folders`
6. Linux 虚拟机：默认 `/mnt/hgfs/`

### 3. 虚拟机克隆

> 
> 快速复制一台一模一样的虚拟机，适合批量部署。

1. 虚拟机**完全关机**
2. `虚拟机 → 管理 → 克隆`
3. 源：当前虚拟机状态
4. 克隆类型：
   - **链接克隆**：体积小，依赖原虚拟机，原虚拟机删除则克隆失效，适合临时测试
   - **完整克隆**：独立完整副本，体积大，可以单独移动、迁移，生产推荐。

### 4. 虚拟机迁移

完整克隆或者直接复制虚拟机整套文件夹，在另一台 VMware 打开「打开虚拟机」选中`.vmx`文件即可。

## 七、快捷键汇总

表格

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Alt` | 释放鼠标，退出虚拟机窗口 |

| `Ctrl + E` | 关机 |
| `Ctrl + Shift + S` | 拍摄快照 |

## 八、常见问题排错

1. **此主机不支持 Intel VT-x**
   - 进入 BIOS 开启虚拟化；Windows 关闭 Hyper-V、WSL2 内核隔离。
2. **虚拟机黑屏**
   - 虚拟机设置 → 显示器，取消「加速 3D 图形」；更新 VMware Tools。
3. **复制粘贴 / 拖拽失效**
   - 确认 VMware Tools 已正常安装并运行；重启虚拟机。
4. **NAT 模式虚拟机无法上网**
   - 顶部菜单「编辑 → 虚拟网络编辑器」，重置 NAT 和 DHCP 服务，重启 VMware。

## 九、最佳实践建议

1. 虚拟机文件不要放在系统盘，防止 C 盘爆满。
2. 测试环境大量快照用完及时删除，避免磁盘膨胀。
3. 重要环境使用**完整克隆**做备份，不要只依赖快照。
4. 做开发推荐 NAT；局域网服务测试用桥接；病毒 / 恶意代码测试使用 Host-only 隔离网络。
