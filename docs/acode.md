Acode 是一款**完全免费**的跨平台手机代码编辑器，同时也是移动端轻量化IDE，完美适配 Android 与 iOS 系统。让编程摆脱电脑束缚，通勤、出差、旅行碎片化时间，都可以随时随地阅读、编写、调试代码。

## ✨ 核心功能特性
- **百种语言语法高亮**
内置 Ace Editor 内核，支持**100+编程语言**语法高亮，覆盖前端（HTML/CSS/JS/TS）、Python、Java、Go、C/C++、PHP、Rust、Kotlin等主流开发场景；支持代码折叠、代码缩进、查找替换、文件符号跳转。搭配LSP插件后，可以实现智能代码补全、错误提示，拥有类似PC端IDE的IntelliSense体验。

- **项目管理与Git原生集成**
支持多标签页同时打开多个文件，管理完整项目文件夹；内置Git工具，可直接提交、拉取、推送代码，访问GitHub/Gitee仓库，不用切换App。自带命令面板，快捷键体系对标VS Code，PC端的操作习惯可以直接迁移到手机。

- **插件生态扩展（高度自定义）**
拥有丰富社区插件市场，可自由安装各类扩展，像VS Code一样灵活定制编辑器能力：
  - **AcodeX插件**：对接Termux终端，在编辑器内直接唤起Linux终端，搭建完整后端运行环境，执行npm、pip等命令，调试后端代码；
  - Web预览插件：HTML页面实时预览，附带JS控制台调试前端页面；
  - AI编码插件：接入AI代码助手，代码补全、解释代码、生成片段；
  - 主题、Emmet、FTP/SFTP文件上传等工具插件。

- **轻量化，上手门槛低**
安装包体积小巧，无广告、无追踪收集；新手可以快速上手，编写单文件代码、做简单脚本测试；资深开发者也能搭建完整Web、后端开发工作流，甚至可以直接在手机完成项目构建与部署。

## 📌 适合人群

2. 开发人员：外出临时改bug、阅读项目源码、简单调试；

## ⚠️ 使用提示
1. 手机屏幕尺寸有限，**适合小型项目、脚本开发、代码阅读**；大型工程、重度开发，依旧推荐电脑VS Code；
2. AcodeX对接Termux需要简单配置，初次使用建议参考网上教程；
3. iOS版本受系统沙盒限制，文件访问权限相比Android会弱一些。
